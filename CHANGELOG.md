# Changelog

All notable changes to GlideIt will be documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] — 2026-05-01
### Added
- Initial release
- Python AST extraction with Tree-sitter
- JSX/React component graph extraction
- ELK.js hierarchical layout
- BFS subsystem clustering with color palettes
- Breadcrumb back-trace on node hover
- Depth slider for filtering call depth
- `glideit run` and `glideit serve` subcommands
- Offline-capable standalone HTML output
